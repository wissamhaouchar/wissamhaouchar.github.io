# Wissam Haouchar — Software Engineer Portfolio

Static GitHub Pages portfolio featuring real project screenshots and links.

## Publish
1. Open https://github.com/wissamhaouchar/wissamhaouchar.github.io
2. Upload **index.html**, **assets/** and **Wissam_Haouchar_Resume.pdf** to the repository root, replacing the previous index.html.
3. Commit to main. GitHub Pages updates automatically (may take a few minutes).
4. Visit https://wissamhaouchar.github.io/ and hard-refresh (Ctrl+F5).

## Notes
- All featured screenshots were provided by the portfolio owner.
- No build process or npm installation needed.
- The portfolio is responsive and includes screenshot galleries.
- Resume PDF included. Review resume and project descriptions before publishing.
- Do not upload this README unless desired.
